### Repository Structure

- `days/` — One folder per Jeremy’s IT Lab day (lecture notes + labs)
- `domains/` — High-level summaries mapped to official CCNA exam domains
- `resources/` — Cheatsheets, command references, and study aids

### How to Use This Repo

1. Browse by day in the `days/` folder.
2. Each day typically contains:
   - `README.md` → Lecture notes + key concepts
   - `lab.md` → Lab steps, commands, and verification
   - `configs/` → Running configurations
   - `images/` → Screenshots and diagrams
